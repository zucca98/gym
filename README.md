# CrossFit WOD Tracker 💪

A comprehensive CrossFit Workout of the Day (WOD) tracking application built with React, TypeScript, and Tailwind CSS. Track your workouts, monitor progress, and achieve your fitness goals with detailed analytics and insights.

## ✨ Features

### 🏋️ Workout Management
- **Exercise Library**: Comprehensive database of CrossFit exercises with categories, difficulty levels, and equipment requirements
- **Workout Builder**: Create custom workouts with different types (AMRAP, For Time, EMOM, Tabata, etc.)
- **Workout Templates**: Save and reuse your favorite workout configurations
- **Quick-Start Workouts**: Access popular CrossFit benchmark workouts

### ⏱️ Advanced Timer System
- **Multiple Timer Types**: Countdown, Stopwatch, AMRAP, EMOM, and Tabata timers
- **Visual & Audio Cues**: Color-coded backgrounds and sound notifications
- **Customizable Settings**: Adjust work/rest intervals and rounds
- **Full-Screen Mode**: Distraction-free timer interface

### 📊 Comprehensive Analytics
- **Workout Statistics**: Track total workouts, current streak, and time spent training
- **Progress Visualization**: Weekly and monthly progress charts
- **Performance Trends**: Monitor your feeling ratings and workout consistency
- **Personal Records**: Track and celebrate your achievements
- **Exercise Analytics**: See your most-used exercises and favorite workout types

### 📱 Modern User Experience
- **Progressive Web App (PWA)**: Install on your device for native app experience
- **Dark/Light Mode**: Automatic theme switching based on system preferences
- **Responsive Design**: Optimized for mobile, tablet, and desktop
- **Offline Support**: Continue tracking workouts even without internet
- **Data Persistence**: All your data is saved locally with automatic backup

### 🎯 Goal Setting & Tracking
- **Personal Goals**: Set and track fitness objectives
- **Streak Tracking**: Monitor workout consistency with daily streaks
- **Achievement System**: Celebrate milestones and progress
- **Workout Diary**: Log and review past workout sessions

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn package manager

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/zucca98/gym.git
   cd gym
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to see the application

### Building for Production

```bash
npm run build
npm run preview
```

## 🛠️ Technology Stack

- **Frontend Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS for responsive design
- **Routing**: React Router DOM for navigation
- **Icons**: Lucide React for consistent iconography
- **Build Tool**: Vite for fast development and building
- **PWA**: Service Worker for offline functionality
- **State Management**: React Context API with localStorage persistence

## 📱 PWA Features

This app is a Progressive Web App (PWA) with the following capabilities:

- **Installable**: Add to home screen on mobile devices
- **Offline Support**: Continue using the app without internet connection
- **Background Sync**: Sync data when connection is restored
- **Push Notifications**: Workout reminders (when implemented)
- **App Shortcuts**: Quick access to key features

## 🎨 Design Philosophy

- **Mobile-First**: Designed primarily for mobile use during workouts
- **Accessibility**: WCAG compliant with proper contrast and navigation
- **Performance**: Optimized for fast loading and smooth interactions
